# エンドレス（2026-09-27）

ユーザー: 「自由モードとは別に、とにかく適当に集められるモードを。自由モードは美術館や水槽的な位置付け。ストレス発散向けで、あまり何も考えずにガーっと集めてを繰り返すだけ。細かい制限やルールはなく、散らばったカラーを綺麗にまとめていくだけ。全てがまとまった（3色仕分け）時点でクリアとして、達成感を味わえる簡易なエフェクトや効果音。そしてまた散らばる。エンドレスモードのような名称でも。プチプチやポップイットに近い。効率的なものでいいので提案で実装して大丈夫」。作業ブランチ `feat/endless`（`feat/volume` の上）。入口 `?play=endless`。

## 判断

- **自由モードのオプションではなく、独立したモード「エンドレス」**にした。自由は設定（数・色・手ざわり）を眺めて楽しむ場所で、エンドレスは「集める→そろう→散る」の繰り返しそのものが遊び。入口を分けると、開いた瞬間から何も選ばずに始められる。
- 名前はユーザーの案「エンドレス」、一言は「集めて、また散る」。モード一覧ではスコアの隣（どちらも繰り返し遊ぶもの）、自由は最後の行を一枚で使う（7つになったため、奇数の最後は横いっぱい）。

## 決まり

- 元祖の決まりだけ: 同じ色は触れるとひとつに、違う色ははじき合って**混ざらない**（押し込みで混ざる判定は使わない）。失敗しようがない。
- 三色がそれぞれひとつになったら「そろった」。
  - 最後にくっついた色の鈴（クリアと同じ上がっていく音）、光の輪、盤面の真ん中に通算の回数「N そろった」が浮かんで消える、振動。
  - 1.4秒後、3つの大きな雫が順番に（0.18秒おき）**はじける**。分離のしぶきと音（好評だった演出）を使い、次の回の雫がその色ごとに盤面へ散らばって現れる。
- 次の回の数は 18・24・30 のどれか（最初の回は18）。散らばる位置は毎回ばらばらで、同じ色どうしは引き寄せの届かない距離（16）を空け、何も触れない（勝手にくっつかない）。
- 終わりはない。「散らし直す」（スマホは右上のボタン、R）でいつでも新しく散らす。通算の回数は端末に保存（`pura-flow-endless-v1`）。
- 新しい自動加速・磁力・自動補充は足していない（AGENTS.md の境界）。
