# 元祖8ステージのテストプレイ（M4の試作）

2026-09-25。ユーザー依頼「テストプレイできるようにしてください」により、M4着手前の判断（雫の大きさ・押し込み混色）を実際に触って決められる試遊版を作った。

試遊: https://blitast-studio.github.io/pura/?play=stages

## 内容

- 元祖 `levels.ts` の8ステージとサンドボックス（12〜60個、6個単位）。色・個数・目標割合・必要純度・星の基準・第6面の潮流は元祖どおり。クリア判定は `PuraSim.coreStats`/`checkWin` をそのまま使用。
- 比較の切り替え（画面上部、URLにも保存）:
  - 雫の大きさ: 大きめ（案A、半径×1.5）/ 元祖の大きさ（案B）。`scale=large|original`
  - 混ぜ方: 押し込み0.35秒（入口プレイと同じ `held-press`）/ 元祖の判定。`mix=press|legacy`
- 盤面は420×560の固定。配置は元祖の生成方法を、ステージごとに同じ結果になる乱数で再現（やり直しても同じ盤面）。
- 同色の雫は引き合う距離（12）より離して配置し、触る前に勝手に融合しないようにした（要件7.2）。元祖の配置では6の隙間があり、大きめでは5秒で14→11個などと自動融合していた。第6面は場の流れで動くのが元祖の仕様なので例外。
- 雫の高さ: ほかの画面の固定高さ（0.88）は小さな雫では縦長の柱になるため、ステージだけ半径に比例（承認済み入口プレイと同じ高さ/半径≈2.6、上限0.88）。
- HUD: 色ごとの核の進み（質量/目標）、必要純度、つかんでいる雫の色と純度。クリアは盤面上部の小さな表示（星・秒・次へ）で操作を止めない。最高の星をブラウザに保存（`pura-flow-stages-v1`）。
- 音・振動・分離のしぶき・縁の波・形からの床光は他画面と共通。

## 検証

- 型検査、テスト（ステージ新規6: 全ステージの個数・色・初期の重なりなし、同じ盤面の再現、1.5倍と目標割合、純色の核で星3つのクリア・サンドボックスは無クリア、混ぜ方と個数設定、触らなければ融合しない）。
- GPU描画のヘッドレスChrome（390×844）で第1・4・6面、サンドボックス60個を表示・操作。警告エラー0。比較画像 `artifacts/stages/size-a-vs-b-stage4.png`。
- 描画時間は上限なしで1コマ2.5〜5 ms（第8面42個含む）。計測時のMacはバッテリー駆動で画面更新が30 Hzに制限されていたが、ゲーム側の負荷ではない。
- 実機での難易度・大きさの好み・押し込み判定の好みは、ユーザーのテストプレイ待ち。

## ユーザーのテストプレイ結果（2026-09-25）

スマホで全8ステージをクリア。「ほかと混ざらないようにするときなど意外と頭を使う感じで面白さを感じた」との評価。大きさ（案A/B）・混ぜ方の選択とiPhoneの音の結果は確認待ち。

## ユーザーの決定（2026-09-25）

- 雫の大きさ: 大きめ（×1.5）を既定に確定。スマホで雫の綺麗さが分かりやすいため。
- 混ぜ方: 押し込み0.35秒を既定に確定。元祖の判定は難易度が高め。
- 比較用のボタンは「遊び方と表示」の中へ移動（元祖の大きさ・元祖の判定は引き続き選べる）。
- 音: iPhoneでも問題なし。マナーモード中は鳴らさない（Safariの標準動作のまま、`navigator.audioSession` で上書きしない）。
- 将来候補（未着手）: 自由モード。粘度・慣性・摩擦・色の種類などを設定で変えられる遊び。
