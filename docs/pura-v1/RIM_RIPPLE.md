# 縁が波打つ柔らかさ（比較用の試作）

2026-09-24、提案3として実装。承認版を既定のまま残し、設定「縁が波打つ（試作）」または `?ripple=on` で比較する。作業ブランチ `feat/sensory-feedback`、ソース `70ef3f6`。

- 一粒: https://blitast-studio.github.io/pura/?lab=droplets&ripple=on
- 3面: https://blitast-studio.github.io/pura/?play=chapters&ripple=on
- 融合: https://blitast-studio.github.io/pura/?lab=fusion&ripple=on

## 何が変わるか

1. **縁のさざ波**: 承認済みの揺れ（全体が楕円に伸び縮みする2つ山の動き）はそのまま。その上に3・4・5つ山の縁の波を重ねる。壁・石に当たった側、つかんだ位置、離した瞬間の進行側、融合で小さい方が合流した側から揺れが始まり、数回揺れて収まる。
2. **押し付けたまま潰れる**: 承認版は壁に当たって縮むとき中心へ向かって縮むため、壁との間に一瞬隙間ができていた。試作では当たった側を壁（石）に付けたまま潰れ、離れる動きに入ると補正が消える。

撮影比較（MacのGPU描画、壁に当たった瞬間から17 msごと）: `artifacts/ripple/wall-impact-strip.png`、拡大 `wall-impact-zoom.png`。承認版は中心へ縮んで壁から離れる。試作は壁側が平らな「D」字形で押し付けられ、約85〜120 msで壁側がわずかに尖る揺れ戻しを経て、約170 msでほぼ同じ形に戻る。

## しくみと境界

- 表示だけの変形。物理の位置・当たり判定・量・色成分は変えない。
- 波の高さは毛細管波の比に合わせる（周波数 ∝ √(k(k²−1))、基準は承認済みの3.1 Hz）。3つ山は約6.2 Hz、4つ山は約9.8 Hz、5つ山は約13.9 Hz。減衰は次数とともに緩やかに強める。1フレームの長さに依存しない厳密解で進める。
- 壁へ押し付け続ける間は毎段で接触が起きるため、静かな時間の後の最初の接触だけが波を起こす。押し付け中は「付けたまま潰れる」補正だけが働く。
- 同じ縁の形を、見た目のメッシュ、屈折の出口探索、融合中の形状場、床の影・光の模様で共有する。輪郭・映り込み・影の形が食い違わない。
- 波の合計量に上限を設け、水平断面が常に凸になるようにした（Σk²|c_k| ≤ 0.9）。屈折の出口が一つに定まる前提を保つ。上限は小さめで、目立つのは主に3つ山。
- 波が収まれば従来の軽い光路計算へ戻る。「揺れを控えめに」では無効。「形だけを見る」（不透明表示）には縁の波を反映していない。
- 一粒の実験のカメラの引きは変えていない。盤面の隅で最大に揺れた瞬間、縁が画面端に最大で数％近づく可能性がある。

## 検証

- 型検査成功、79テスト成功（新規8: 静止時は円、当たった側から凹んで揺れ戻り収まる、押し付け続けても震え続けない、どんな連続衝撃でも凸を保つ、30/60 fpsで同じ応答、つかむ・離すの揺れの範囲、座標回転の一貫性、押し付け補正の量）。
- 既定（揺れなし）の見た目は、公開中の承認版（Pages `c4eee52`）と一粒・第3面の静止画で画素単位の差0。`artifacts/ripple/default-pixel-identity.json`。
- 公開版（Pages `c7c0e7f`）をヘッドレスChrome（Apple M1のGPU）で操作: 一粒で縁の波最大0.036・押し付け補正最大0.060、3面・融合で融合と揺れあり描画、各60 fps、警告・エラー0。`artifacts/ripple/public-check.json`。
- スマホ実機の描画負荷（波が出ている間は出口探索が16段の二分探索になる）、指で触ったときの印象は未検証。気持ちよさの判断はユーザーの比較試遊待ち。
