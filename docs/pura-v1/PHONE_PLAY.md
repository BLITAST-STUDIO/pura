# スマホでは盤面だけ（2026-09-27）

ユーザー: 「スマホで遊ぶときのことを考えてUIを整理したい。画面が小さいスマホだとUIはできるだけ減らし、遊ぶプレイエリアだけの表示にしたい。必要なときにメニューを呼び出せる仕様に」。作業ブランチ `feat/phone-play`（`main` から）。

## 仕様

- 対象: 画面の幅540px以下、または高さ520px以下（スマホの縦・横）。PC・タブレットは従来の画面のまま（公開版と画素差0）。確認用に `?layout=phone` / `?layout=page` で強制できる。
- 遊んでいる間: 盤面が画面いっぱい。左上にメニュー、右上にやり直す（やり直しのない場面では出さない）。盤面上の小さな表示（何打目・純度・残り）は残し、スマホでは文字を少し大きく。
- 描画: スマホでは、盤面の四隅が画面の左右ぎりぎりに来るまでカメラを寄せる（上下は操作ボタンと表示のために少し空ける）。PCのカード表示の余白はそのまま。
- メニュー: 開くと一時停止し、盤面を隠して、その画面の他の部分（モードの切り替え、章・ホール・回り方、目標、スコアカード、設定、遊び方）がそのまま出る。「盤面に戻る」で閉じると、開く前の一時停止の状態に戻る。面・ホールを選ぶ、やり直す、カーリングで新しい試合を始めると、閉じてすぐ遊べる。設定を変えるときは開いたまま。
- 盤面の上に残す、遊びに要るもの:
  - 道・スコア: 目標の進み具合（色ごとの細いバー）。
  - カーリング: 回転の切り替え（タップで ↺左 → なし → 右↻）と、見出しに点数（END 2 · 1–0）。
- 対象の画面: はじめる・道・ひとふで・カーリング・スコア（と元祖8ステージ）・自由。三つの道（旧）と元祖PURAは従来のまま。

## 検証

- 型検査・158テスト（画面の大きさでの切り替えと強制）・ビルド成功。
- ヘッドレスChrome（390×844、GPU）: 6画面すべてで盤面が画面いっぱい（390×844）、モード切り替えなどが隠れ、ボタンが出る。カーリングの回転ボタンと点数、道・スコアの目標バー。道でメニューを開くと一時停止・盤面が隠れる・「盤面に戻る」、面2-4を選ぶと閉じて2-4へ。スマホ表示で、ひとふで5番を引いて離して1打で決められる（入力の対応が正しい）。横向き（844×390）でも盤面が高さいっぱい。
- PC（900×820）のはじめる・道・ひとふで、スマホ幅で `?layout=page` の道は公開版と画素差0。
- 画像 `artifacts/phone/portrait.png`（道・メニュー・ひとふで・カーリング）、`artifacts/phone/landscape.png`。
- 実機（iPhone・Android）での指の操作感は未確認。

## 盤をひとまわり大きく（2026-10-03）

ユーザー:「スマホでの道などのUIはどうなっているか。プレイ時は盤が大きく、メニュー類はたたんで必要なときだけ呼び出せるように。ゲーム上必要なものは出し続けてよい。極力シンプルに」。「おすすめ順で」と了承。作業ブランチ `feat/phone-bigger-board`（`main` から）。

### 現状の確認（変える前）

- スマホ幅（540px以下または高さ520px以下）では、盤が画面全体、ページはスクロールしない。常に出ているのは、左上のメニュー、右上のやり直し、上の面名と残りの数、下のゲームの状態（道は純度のバーと「3 DROPS」「純度 99% 以上」、カーリングは「回転」のボタンと一行の説明）。ほかはすべてメニューの中（開くと一時停止）。9つの画面（はじめる・道2面・ひとふで・カーリング・スコア・ステージ・エンドレス・自由）で確認。
- 盤の幅は画面の約89%（縦長の画面では幅がいちばんの制約で、高さは余っている）。原因は、カメラが盤の外側の隅を画面の端に合わせ、実際に見える枠（壁の約12単位外）との間に、左右約4%ずつの余白が残っていたこと。

### 変更

- 幅は**枠（リム）を画面の端**に合わせる（`fit: 'screen'` のカメラ、`renderer.ts`）。高さは従来どおり盤の隅で合わせ、上下のボタンと表示の余裕を保つ。傾き・物理・表示物は変えていない。
- 縦持ちの3つの大きさ（390×844、360×740、430×932）で、枠の幅が画面の約89%から**約94.5%**（左右の余白は約5.5%から約2.7%）。盤の面積では約12%増。横持ち（844×390）は高さが制約で、変更なし（下のバーと重ならないことを確認）。
- 全モード（はじめる・ひとふで・カーリング・自由・エンドレス・スコア・自作ひとふで）で、枠の幅は同じ約94〜95%、切れなし。雫を左の壁へ強く押し込んでも、雫は画面内に収まる。
- 未実施: 常時表示（道の純度のバーなど）の整理。道では「いまの状態を知る」手がかりなので、実機で盤の大きさを見てもらってから判断する。傾きを減らして盤をさらに大きくする案（見た目が変わるので承認が要る）。
- 検証: 型検査・202テスト。画像 `artifacts/phone/board-before.png`・`board-bigger.png`。
