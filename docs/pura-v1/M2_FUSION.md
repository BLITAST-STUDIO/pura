# M2 — 融合の最初の試作

2026-09-17。ユーザーが一粒の質感・操作を承認し、次へ進むよう指示したため着手。人による融合の感覚評価はこれから。

## 試遊

https://blitast-studio.github.io/pura/?lab=fusion

- 「ふたつの雫」: 同色二滴を触れ合わせる。掴み中でも解放後の滑走中でも融合する。
- 「色をまぜる」: シアン／ローズの自由混色。1:1、4:1、1:4、10:1、1:10を選べる。比率変更で並べ直す。ここでは異色も接触で融合することを画面に明記した。
- 「つづけて融合」: 五滴をまとめる。演出中も再操作・再融合できる。
- 照明、屈折を見る、形だけを見る、揺れ抑制、画質、一時停止、並べ直しを用意。盤面から始めたタッチはスクロールを抑止する。
- 一粒は `?lab=droplets&feel=refined` で継続。フッターに融合へのリンクを追加した。

## 保存と実装の境界

承認された一粒はタグ `m1-approved-20260917` / commit `5b5ca41021e4ff39977a63594645100a90588e93` としてGitHubへ保存・照合。以前の `m1-praised-baseline-20260916` も維持。M2は `feat/droplet-fusion` で作業する。

既存PuraSimには、コピーした親二滴と結果を渡す `onFusion` と、既定がlegacyの `fusionPolicy` を追加した。位置・質量・速度・入力継承は既存融合演算を使う。自由混色の実験だけ `all-colors` を選ぶ。旧ゲームの通常ルールは変えない。

既存の異色押し込み条件は大きな重なりと低い相対速度を同時に要求する。現在の衝突押し戻しと組み合わせた試行では成立しなかった。今回の材質試作でそこを難易度として強要せず、明示的な自由混色に分けた。基本モードの公平な混入条件は次の検討事項。

一粒のレンダラーの床・照明・影生成関数をexportして再利用。既存の材質・物理・揺れの値は維持。新しい画面は独立アダプターで三成分を持ち、照明変更で成分を書き換えない。

## 表面と光学

融合成立前は独立した滴。成立後は親の位置を引き継ぐ楕円体の滑らかな和を、一つの閉じた表面として生成する。MarchingCubesは導入済みThree.jsのaddonを使用し、依存追加なし。連続融合では親の残る形を引き継ぐ。

最初の約0.85秒は40³の場からメッシュを生成し、実際の三角形から体積を算出してXYへ補正する。以後は既存と同型の高密度メッシュへ戻す。物理の `mass=r²` を継続し、基準高さを一定にすることで量と幾何体積を対応させた。M1の半径88に合わせた高さを基準とする。この高さ則は床上の液量を表す試作上の近似で、自由な球状液滴の平衡形状モデルではない。極端な大小比の見え方は試遊で評価する。

形状場と内部光路の出口は共通の式を使う。融合中の内部交差は回数上限付きの走査と二分探索。表面の反射と内部の吸収を分離し、M1の二界面屈折・Fresnelを再利用する。複数の独立した滴を通る多重屈折は未実装。

移動・指の先行変形・触れ始めの微小応答はM1の部品を再利用。接触軸と内部色が進行方向の変化で勝手に回らないよう、方向付きの伸縮を行列で適用。融合には短い減衰する形状の揺り戻しを加え、物理速度へ加速を追加しない。影・集光の近似も融合中のふくらみへ追従する。

## 成分と内部色

純色の吸収係数はM1の純色変換から導出し、各色の成分比で混ぜる。組成は融合時に確定する。表示だけ、接触側の二色領域が流れて約2.5秒で均質な吸収へ収束する。揺れ抑制では内部の渦を出さず最終比率を使う。

この内部模様は、重み付きの色領域を変形させる近似。実際の3D移流拡散ソルバーではなく、途中の局所濃度を厚み積分した量の厳密保存は未検証。正しい全体成分と最終吸収は常に別で保持する。内部全反射時の染料積分も一本の区間への近似が残る。混合時間・渦・反動は演出値であり実液体の物理定数ではない。

## 今回の先に残ること

RYOによる融合の感触評価、スマホ実機の性能、極端な大小の高さ・接地感、融合直後の再吸収時の細かい形と色の連続性を磨く。内部模様は近似から必要に応じて改善する。基本モードの純度目標・混入判定・一手戻す・ステージ統合は今回の実装に含めない。

## 内部の渦の比較試作

ユーザーの融合への高評価を受け、`m2-approved-20260917` に現状を保存。試作は `?lab=fusion&mixing=swirl` で開く。設定「色のなじみ方」で「ゆるやかな渦（試作）」と「これまでの混ざり方」を切替可能。通常の `?lab=fusion` は従来分岐のまま。

色の座標だけを、接触軸の近くにある二つの弱い渦で曲げる。深さで境目をわずかに変え、接触位置と速度から決めた位相を融合中は固定する。フレーム乱数、泡、白濁、表面の回転、物理への力は追加しない。既存の2.5秒で最終吸収へなじむ。揺れ抑制時は即座に最終比率を描く。

最初の案は見た目の差がごく小さかったため、渦の局所角を少し増やしてブラウザで比較した。1:1の0.33〜0.58秒の画像、1:10／10:1の成分量と操作、従来表示への切替を `artifacts/m2/swirl/` に記録。静止画像は流れの感覚評価の代わりではない。実機性能は未検証。光線サンプルは8回のままだが、混合中の座標計算は増える。均質になった後は早期returnで渦計算を省く。
