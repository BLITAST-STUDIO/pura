# 三つの道

試遊入口: https://blitast-studio.github.io/pura/?play=chapters

ユーザー承認により、好評だった一面を基準に3面へ展開。復元タグ `first-scene-approved-20260917`、作業ブランチ `feat/three-purity-chapters`。

1. 澄んだ道: 承認された配置でシアン三滴を純度90%以上で運ぶ。
2. 小さなうちに: シアン三滴と固定された丸い石。中央の隙間94に対し一滴の直径72、二滴融合で約102。小さいまま通すか、先にまとめて外側を回る。石は円形の剛体障害物で、狭い道への押し潰しは実装しない。
3. ふたつの行き先: シアン二滴・ローズ二滴を色別にまとめ、左と右の同色名の輪へ。それぞれ90%以上の純度が必要。

全色接触融合、半径二乗の量保存、承認済みbloom描画を継続。各輪は全体収容・解放・低速0.45秒で達成。二色は順番に運べる。全目標の達成後はクリア状態を保持し自由に触れる。時間制限・強制遷移なし。

面選択は最初から全3面を選べる。次の面ボタン、達成バッジ、最後に開いた面を追加。`pura-flow-chapters-v1` に達成した面番号と最後の面だけを保存する。ブラウザごとの記録で、途中配置の保存・端末間同期はない。旧 `pura-save-v1` は変更しない。保存不可でも遊べる。`?play=first` は引き続き第1面から開始。

## 検証

- 型検査成功、55テスト成功。狭い隙間の大小判定、外回りルート、二色の達成と取り消し、入力だけで第3面を解けること、保存の妥当性・旧キー保護・保存不可を検証。
- Macブラウザ390×844で第2面をドラッグして全融合→外回り→クリア。「次の面へ」で第3面へ移動し、再読み込み後も第2面の達成表示を確認。第2面の石と第3面の二色の輪を表示確認。コンソール警告・エラーなし。
- 実機タッチ、長時間性能、初見の難易度評価は未検証。静的な石との接触で外形が石に沿って潰れる流体計算は含まない。
