# 道 — 四つの章（2026-09-27）

ゲームの組み立て（B、2026-09-26承認）の「道」を仕上げたもの。ユーザー承認（「おすすめ順開発でお願いします」）で、ひとふでのコースの次に着手。作業ブランチ `feat/michi`（`main` から）。入口 `?play=michi`（面は `&board=11` など）。

## 決まり（全面共通、元祖PURA）

同じ色は触れるとひとつに、違う色ははじき合う。つかんで押し込むと0.35秒で混ざる。混ざった雫はすばやく2回たたくと分かれる。星は元祖どおり、純度99.5%以上で3つ、必要な純度+4%以上で2つ。時間制限なし。三つの道の「どの色も触れると混ざる」決まりと「一手戻す」は、道では使わない（統一のため）。

- 元祖の面: 色・数・大きさ（ユーザー決定の×1.5）・必要な割合・純度・流れは元祖の値。置き方はステージ画面と同じ種から作るので、同じ面は同じ配置（テストで確認）。
- 三つの道の面: 550×650などの盤面を、ステージと同じ420×560の枠に等倍で縮めて中央に置いた。石の門は「一粒なら通れて、二つ合わさると通れない」関係を保つ（テストで確認）。縮めたことで4-1の雫どうしが引き寄せの届く距離（12）まで近づき、触る前にくっついていたため、同じ色の間を14以上に広げた（全面で「3秒触らなくても数が変わらない」をテスト）。
- 輪の面: その色の雫を全部ひとつにまとめ、純度が足りた状態で輪の中に0.45秒止まると届く（三つの道と同じ考え方）。持ったままでは届かない。
- 第3章の一文: 一度も分離していなければ、3-1は25秒、3-2は40秒後に静かに出る。

## 画面

- 章（4つ、各章の星の合計）→ 面 → 盤面。クリアすると「次へ」で次の面（章をまたぐ）。最後に遊んだ面を覚えている。
- モード切り替えは「はじめる・道・ひとふで・スコア・自由」。元祖8ステージ（`?play=stages`）と三つの道（`?play=chapters`）の画面は残し、道の下部リンクから開ける。スコアアタックは元祖8ステージのまま。
