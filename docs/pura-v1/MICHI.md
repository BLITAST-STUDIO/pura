# 道 — 四つの章（2026-09-27）

ゲームの組み立て（B、2026-09-26承認）の「道」を仕上げたもの。ユーザー承認（「おすすめ順開発でお願いします」）で、ひとふでのコースの次に着手。作業ブランチ `feat/michi`（`main` から）。入口 `?play=michi`（面は `&board=11` など）。

## 決まり（全面共通、元祖PURA）

同じ色は触れるとひとつに、違う色ははじき合う。つかんで押し込むと0.35秒で混ざる。混ざった雫はすばやく2回たたくと分かれる。星は元祖どおり、純度99.5%以上で3つ、必要な純度+4%以上で2つ。時間制限なし。三つの道の「どの色も触れると混ざる」決まりと「一手戻す」は、道では使わない（統一のため）。

## 章と面（16面）

| 章 | 面 | 出どころ | 目標 |
|---|---|---|---|
| 1 融ける | 1-1 ひとつに / 1-2 すべらせて / 1-3 しずく集め | 新しく設計 | 一色を核に（1-1・1-2は全部、1-3は90%） |

| 3 混ぜて、分ける | 3-1 にごり / 3-2 ほどく | 2026-09-26の発見面 | 分離しないと達成できない数値 |
| | 3-3 臨界 | 元祖05 | 元祖どおり（純度97%） |

- 元祖の面: 色・数・大きさ（ユーザー決定の×1.5）・必要な割合・純度・流れは元祖の値。置き方はステージ画面と同じ種から作るので、同じ面は同じ配置（テストで確認）。
- 三つの道の面: 550×650などの盤面を、ステージと同じ420×560の枠に等倍で縮めて中央に置いた。石の門は「一粒なら通れて、二つ合わさると通れない」関係を保つ（テストで確認）。縮めたことで4-1の雫どうしが引き寄せの届く距離（12）まで近づき、触る前にくっついていたため、同じ色の間を14以上に広げた（全面で「3秒触らなくても数が変わらない」をテスト）。
- 輪の面: その色の雫を全部ひとつにまとめ、純度が足りた状態で輪の中に0.45秒止まると届く（三つの道と同じ考え方）。持ったままでは届かない。
- 第3章の一文: 一度も分離していなければ、3-1は25秒、3-2は40秒後に静かに出る。

## 画面

- 章（4つ、各章の星の合計）→ 面 → 盤面。クリアすると「次へ」で次の面（章をまたぐ）。最後に遊んだ面を覚えている。
- モード切り替えは「はじめる・道・ひとふで・スコア・自由」。元祖8ステージ（`?play=stages`）と三つの道（`?play=chapters`）の画面は残し、道の下部リンクから開ける。スコアアタックは元祖8ステージのまま。
- ステージ画面にあった第3章の試作段は道へ移した。

## 道のおわり（2026-10-04）

ユーザー:「道は全ステージが終わっても、クリアや完了の表示が出ないのでは。やりきったことが分かるものがいい（放置気味になる）。クリア確認後に、終わるっぽいボタンを置き、押すと白くまぶしくなる演出でメニューに戻るUXに」。作業ブランチ `feat/michi-finale`。

- これまで: 最後の面（4-5）をクリアすると星と秒数が出るだけで、次の面がないので「次へ」も消え、そのあとの案内はなかった。
- 追加: 最後の面のクリアのカードだけ、「次へ」の代わりに **「道をおわる」**（濃い緑のボタン）。ほかの面は従来どおり「次へ」。
- 押すと、白が満ちる（一瞬、明るさを超えるまぶしさから、やわらかい白へ。約2.6秒）。そのあと、一行「道を、歩ききりました。」、全16面の星の合計（例「星 41 / 48」）、7つの遊び方の入口（メニューと同じ一覧、いまの「道」に印）、「道を見返す」。遊び方を選べばそのモードへ、「道を見返す」で最後の面に戻る。
- 面の選択や、ほかの面のルールは変えていない。動きを減らす設定（reduced motion）では、白は一瞬で、文字はすぐに出る。
- `?play=michi&board=45&finale=1` で、道を最後まで遊ばずに、この終わりの画面をすぐ見られる。
- 検証: 型検査・210テスト（星の合計は各面3まで・負にならない・知らない面は無視、最後の面だけ次がない・ほかの15面は次がある）。ブラウザ（GPU、スマホ幅）: 途中の面（4-4）を実際に遊んでクリアすると「次へ」のまま、終わりの画面（白の直後と落ち着いたあと）、遊び方を選ぶとそのモードへ（エンドレス）、「道を見返す」で戻る。警告エラー0。画像 `artifacts/michi/finale-flash.png`・`finale.png`。
- 未確認: 最後の面（4-5）を実際に遊んでクリアしたときの流れ（確認用の簡単な操作では、この面をクリアまで運べなかった。分岐はテストで確認、ユーザーの実機で最後まで）。
