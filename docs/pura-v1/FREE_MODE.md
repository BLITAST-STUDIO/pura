# 自由モード

2026-09-26。ユーザーの「ストレス発散なら制限なし」「玉を適当に動かしてゴゴゴッと集める快感も楽しめるモード」「粘度・慣性・摩擦・色の種類などをいじれる」を実装。目標・点数・自動補充なし。

試遊: https://blitast-studio.github.io/pura/?play=free

## 設定

- 雫の数 6〜60（6刻み）、色 1〜3色、混ざり方（同じ色だけ／押し込むと混ざる／触れると全部混ざる）。数と色を変えると並べ直し、他は触ったまま即反映。
- 粘度（さらさら〜とろり）: 1/60秒あたりの速度保持 0.998〜0.968。
- 慣性（機敏〜重い）: 指と雫のばね 74〜約9、その減衰 13〜5。
- 摩擦（なし〜強い）: 一定の滑り摩擦 0〜420。つかんでいる雫には掛けない。
- 引き寄せ（なし〜強い）: 元祖の弱い同色引力・異色反発の倍率 0〜2。
- おすすめ: 標準（元祖の手触りに一致: 保持0.992・ばね約35・減衰10.2・摩擦0・引力1）、さらさら、とろり、ゴゴゴ（1色60個・引き寄せ強め。三色すべてを混ぜると濁った灰色の一滴になるため1色にした）。
- 設定はブラウザに保存（`pura-flow-free-v1`）。雫の大きさはステージと同じ×1.5、高さも同じ比例。同色は引き合う距離より離して配置し、場所が足りないときは少し小さくして置き直す（触る前に融合しない）。

## 物理の変更

`PuraSim.tuning`（`Tuning` 型）を追加。既定値は元祖の定数（`LEGACY_TUNING`）そのもので、ほかの全モードの挙動は変わらない（既存104テストがそのまま成功）。自動加速や磁力コンボではなく、プレイヤーが明示的に選ぶ設定。

## 検証

- 型検査、109テスト成功（自由モード5: 標準＝元祖の値、粘度と摩擦で滑走が短く摩擦で止まる、慣性で追従が遅れる、数・色・混ざり方と即時反映、引き寄せ2倍でも触る前に融合しない）。
