# PURA — 受け入れ検証計画

要件定義v1.0 / 2026-09-16

**以下は検証の設計であり、実行済みテストではない。** 各結果には実施日、HEAD、環境、実行手順、証拠、合否／未実施を付ける。要件IDはREQUIREMENTS.mdを参照。

## 1. 検証の基本

物理・入力は固定した条件で比べる。描画のランダムな見え方や別の初期配置で新旧を比較しない。固定盤面を読み込むために小さなテスト用アダプターを作れるが、ゲーム全体のリファクタリングに広げない。

1個の見た目、2個の融合、5個の連鎖、12/24個の実プレイ、60個の最大初期数を別々に検証する。M1の合格でM2以降まで合格した扱いにしない。

自動テスト、実ブラウザ確認、実機性能、RYOの感覚評価を区別する。新旧比較で差が出たら、意図した美術差／承認済み仕様差／回帰不具合へ分類する。

## 2. 物理とルール

| 検証ID | 関連要件 | 条件・操作 | 期待結果 |
|---|---|---|---|
| T-G01 | G-01/G-03/G-07 | 同じ主成分色の2滴を融合 | 質量と三色の各成分が加算され、1個になる |
| T-G02 | G-02/G-03 | 動く1滴＋静止した同色1滴を融合 | 融合直前直後の速度が質量加重で継承。勝手なブーストなし |
| T-G03 | G-03/G-04 | 小滴を高速で横切る同色 | 掃引判定相当を保ち、描画頻度で吸収を取り逃がさない |
| T-G04 | G-04/I-04 | 5滴程度の列へ一滴を滑らせる | 演出待ちなしで複数を吸収。途中に入力できる |
| T-G05 | G-04/I-04 | 掴んだまま融合→さらに融合 | 新IDへ制御が続き、ポインターが宙に残らない |
| T-G06 | G-05/V-09 | 異色を普通に接触・衝突 | 反発。判定が成立していない混色や見た目の橋が出ない |
| T-G07 | G-06/G-07 | 掴み、低相対速度、十分な重なり | 基準条件で混色。条件の一つを外した対照場面では不成立 |
| T-G08 | G-07 | 低純度の核に高純度の主成分を足す | 成分計算に従って純度が回復。照明変更で数値が変わらない |
| T-G09 | G-08 | 分離可能な混色滴をダブルタップ | 対象の非主成分が取り出され、全質量・成分は保存 |
| T-G10 | G-08 | 純粋な滴／少量しか混ざっていない滴に同操作 | 現行条件に従い自由二分割をしない |
| T-G11 | G-10 | 掴み時と非掴み時の近接場面 | 既存の弱い引力／反発を比較。新しい磁力コンボへ変えない |
| T-G12 | G-11 | 核の質量・純度を境界値の前後へ固定 | 基準coreStats/checkWinと一致。成分質量と総質量を混同しない |
| T-G13 | G-12 | サンドボックスをまとめ、放置 | 勝利・時間切れ・自動補充なし。操作とリセットは可能 |
| T-G14 | G-03/G-07 | 同率の主成分、微小量、混色同士 | palette.tsの優先順・微小量処理に一致 |

質量・各成分量の比較の初期案は `abs(actual-expected) <= 1e-6 * max(1, abs(expected))`。テストに使う入力値と許容誤差を記録し、不都合な結果に合わせて緩めない。

運動エネルギーの全場面での保存は要求しない。摩擦、反発係数、外力、ユーザー入力がある。T-G02は減衰などを含めない融合演算の直前直後を切り出して比較する。

新しい描画FPSを30/60/120Hz相当に変える試験では、同じシミュレーション時刻に同じ入力を渡す。経過時間や乱数を揃えずに結果差を描画の問題と断定しない。実機間の完全決定論までは本版で保証しない。

## 4. 描画と水滴らしさ

| 検証ID | 関連要件 | 方法と評価 |
|---|---|---|
| T-V01 | V-01/V-03 | 三色各1個を大小で比較。表面の反射と内部色、薄い縁が区別できる |
| T-V02 | V-02 | 線・小点を含む検査盤面を用意。移動・厚み・変形に対応した背景の歪みを確認 |
| T-V03 | V-04/V-05 | ドラッグ・滑走・壁衝突を録画。輪郭とハイライトが同じ形として動く |
| T-V04 | V-06/G-04 | 2個の融合を通常速度とコマ送りで見る。球の境目、消滅、形状の飛びなし |
| T-V05 | V-06/I-04 | 融合途中の再融合・再操作。演出が巻き戻らない、古い滴が復活しない |
| T-V06 | V-09 | 異色の通常接触と混色成立を比較。成立前の過剰な接続を防ぐ |
| T-V07 | V-07/V-08 | 全盤面の端・角・密集・低品質設定。黒抜け、描画順の切替、触れない雫を探す |
| T-V08 | V-01〜09 | 無音でRYOが触る。水滴に見えるか、硬いガラス／ゴムに見えるか、また弾きたいか |

「屈折して見える」「透明体同士の多重屈折まで正しい」は別の評価。実装していない範囲を明記する。軽量設定で基本表現を失った場合は、画質合格にせず互換モード等として区別する。

静止画には比較の用途があるが、T-V03〜05/T-V08を静止画だけで合格にしない。録画が取れなければ操作手順と未検証を残す。

## 7. 統合版の回帰

M4で8ステージの開始、進行、純度、達成、星、再プレイ、次の面、サンドボックス初期数、設定、既存保存の読み込みを確認する。旧保存のバックアップを作り、実験用キーで検証する。新入口プレイが既存進捗を誤更新しないことも確認する。

初期60個を表示できることと、分離や将来変更で個数が増えた状態へ安全に対処できることは別。レンダラーの上限超過で、見えない当たり判定を残さない。

開発サーバーだけでなく生成した配信用ビルドで、相対パス、素材の読み込み、実験UIの非露出、ゲームの起動を確認する。実際の公開操作は別途承認後。
