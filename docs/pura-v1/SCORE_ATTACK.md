# スコアアタック（試作）

2026-09-25、ユーザー提案「他の色と融合すると吐き出しが使えるが、使うたびにポイントがマイナス。丁寧さとスピードのジレンマ」と、Claude提案のコンボ（「要はコンボ」）を採用。元祖8ステージの上に得点だけを重ねる。物理は変更しない。

試遊: https://blitast-studio.github.io/pura/?play=stages&mode=score （画面の「じっくり／スコアアタック」でも切替）

## 得点

| 項目 | 内容 |
|---|---|
| クリア | 1000 |
| 純度 | 平均純度が必要純度から100%へ近いほど最大1000 |
| 速さ | 1500 × e^(−秒/基準)。基準は 10 + 個数×1.4 秒。強制の時間切れはなし（G-09） |
| コンボ | 同色の純色融合が1.2秒以内に続くと、2連目から20・40・60…（1回最大200）。混ざった融合・吐き出しで途切れる |
| 吐き出し | 1回ごとに −(60 + 600 × 取り出した量/盤面の総量)。小さな混入は我慢するか、吐き出すかの判断になる |

合計は0未満にならない。ステージごとの最高点をブラウザに保存（`pura-flow-score-v1`）。「じっくり」モードは従来どおり得点なし・吐き出し無料。サンドボックスは得点なし。
