# 初見テストの手引き（2026-10-17）

目的: 説明なしで渡したとき、どこで迷い、何が残るかを知る。需要や売上を証明する人数ではない（`LAUNCH_PLAN.md`）。8〜12人、Androidを含める。

## 渡す前に
- 渡すURLは身内版 https://blitast-studio.github.io/pura/ 。初めて開く端末（またはシークレットでない新しいブラウザ）で。
- 記録を引き継ぎたい人には、先に `?play=save`（スマホはメニュー下の「記録の引っ越し」）を案内する。
- 渡す言葉は一言だけ: **「このゲームを、好きなように触ってみてください」**。操作は先に説明しない。手助けしたら記録する。

## 見ること（観察シート `FIRST_TEST_SHEET.csv` に1人1行）
1. 端末・OS・ブラウザ、初回かどうか。
2. 開いてから最初の操作まで（秒）。迷ったか。
3. 「はじめて」で止まった場所。空いた床から引く操作が伝わったか。
4. 自力で別の遊びへ移れたか。10分ほど自由に遊んで、いちばん長く留まった遊び。
5. 音・カクつき・スクロール・中断復帰の問題。
6. 終わりの白い画面に届いたか（届いたら何と言ったか）。
7. 終了後に聞く: 何がよかった／また開くなら何をする／どこまで無料だと思った／完全版の何に魅力を感じるか。
8. 翌日以降の再訪（任意）。購入意向の回答と実際の購入は区別する。

## 渡すときの文面（例）
> PURAという、透明な雫を触って遊ぶゲームを作っています。スマホで開いて、10分ほど好きなように触ってみてください。説明はありません。終わったら、よかったところと迷ったところを教えてください。
> https://blitast-studio.github.io/pura/
> （もし画面がおかしくなったら、URLの最後に `?nosw=1` を付けて開くと直ります）

## 結果のまとめ方
- 止まった場所は、人数を数えるだけでなく「何と言ったか」をそのまま残す。
- 2人以上が止まった所は、ゲーム進行を止める不具合として先に直す。
- 結果は `LAUNCH_PLAN.md` の無料／完全版の範囲案へ反映する。数字の合格ラインは置かない。
