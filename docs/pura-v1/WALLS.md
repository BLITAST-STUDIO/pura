# 壁を見えるように（2026-09-27）

ユーザー: 「ステージの外枠、つまり壁はどうなっているか。プレイエリア端を壁とする手法もいいし、物理的な壁や線で当たると視覚的にわかるようにするかは必要そう。特にはじくモード。壁に当てた跳弾の計算がしやすくなる」。続けて「線画もスタイリッシュでいいかも。シンプルリッチに表現できるか。壁でもいい気もする。まず提案にあるおすすめを採用してみて」。作業ブランチ `feat/walls`（`main` から）。

## それまでの状態

- 壁は物理にだけあり、目に見えなかった。盤面の内側に余白（420×560の盤面で22）をとった長方形で、雫の縁が触れると跳ね返る。
- 斜めから見るカメラのため、画面では台形の位置（上辺は幅の18〜82%・高さ20%、下辺は11〜89%・86%）にあり、その外に「入れない床」が1〜2割見えていた。カーリングの「側面・奥に触れたら場外」も見えない壁だった。
- 跳ね返りは壁に向かう速さの38%（壁に沿う速さはそのまま）。45°で当てると壁から約21°の浅い角度で出る。

## 試作（見た目だけ。物理は同じ）

- **縁（試作の既定）** `?walls=rim`: 壁の線の外側に、低く丸い縁（カプセル4本、角は丸くつながる）。内側の面がちょうど物理の壁。床に柔らかい接地の影を内外に落とす。色は盤面ごと（白い展示室は同じ石の盛り上がりに見える #77736b、スタジオは青灰、夜の水面は暗い艶）。白い展示室では最初の色だと白く飛んだため、3色を比べて選んだ。
- **線** `?walls=line`: 床に象嵌したような二重の細線（壁の位置に髪の毛ほどの線、少し外にさらに細い線）と、内側にごく薄い影の帯。角は小さく丸める。
- **なし（従来）** `?walls=none`: それまでの見た目。公開版と画素差0（入口・ひとふで・カーリング・道2-2で確認）。
- 各画面の「遊び方と表示」の「壁（試作）」でも切り替え。全プレイ画面（はじめる・道・ひとふで・カーリング・スコア・自由・元祖8ステージ・三つの道）に共通。計測ページと実験室は従来のまま。
- 比較画像 `artifacts/walls/compare.png`（白い展示室、3画面×3案）、`artifacts/walls/other-boards.png`（スタジオと夜の水面）。
