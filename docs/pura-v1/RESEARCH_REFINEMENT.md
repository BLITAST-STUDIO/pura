## 採用した改善

研究の確認範囲は [SOURCES.md](SOURCES.md) のR1〜R4に記録した。R1/R2は動的な画像変形と輪郭を一緒に扱う理由、R3は変形方向と力の読み取りを考える参考とした。以下の具体値・形状モデルはPURA用の設計仮説であり、研究が保証する最適値ではない。

| 改善 | 実装と狙い |
|---|---|
| 広がりに合わせて高さを戻す | 既存のXYの揺れ比率を保ち、Zスケールを `1 / (scaleX × scaleY)` にした。壁で潰れたり横へ伸びたりしたとき、描画上の物量が増減する違和感を減らす |
| 指へ上部が先に応答する | 既存の45 msの引っ張りに、小さな上部の曲がりを重ねる。指と本体の距離に対する応答時定数18 ms、戻り85 ms、局所係数の大きさ上限0.065。床に近い部分より上部が先行する |
| 触った瞬間を短く返す | 掴み開始に圧縮係数最大0.028、時定数80 msで消える一度の反応を追加。端を触るとその側へごく小さく曲がる。静止して掴み続けても脈動を繰り返さない。端末の押圧を測定する機能ではない |
| 形と屈折を一致させる | 外側のメッシュ、内部交差の形状、法線へ同じ高さ依存の変形を使う。旧版の微小taperを今回版では置き換え、伸びた表面と内部の光路の不一致を減らす |
| 形そのものを比較する | 設定の「形だけを見る」で不透明な中性色へ切り替える。透明感や色に隠れず輪郭と揺れを見比べられる。集光模様もこの間は隠す。直接指定は `&view=clay` |

表面の局所変形は `x' = x + bendX × (z − bottom)²`、`y' = y + bendY × (z − bottom)²`、`z' = z`。この変形単体は接地平面を動かさず、逆変換を明示でき、ヤコビアンの行列式が1になる。既存の引っ張り変換も行列式1なので、今回版は高さ補償と合わせて連続形状の体積を保つ。三角形メッシュでは離散化・浮動小数点の誤差が残る。

物理の位置・速度・半径二乗の質量則・色成分、既存の追従ばね・滑走・指離しは維持した。屈折率1.333、三色、照明も共通。表面変形のために投射速度や自動加速を足していない。揺れを控える設定、リセット、比較切替では追加応答を適切に解除する。

## 実装の範囲と検証

`surface-response.ts` が入力に対する応答と体積スケール、`surface-shape.ts` が共通形状・逆変換・内部交差を担当する。`renderer.ts` と `liquid-material.ts` が描画へ接続し、`DropletLab.tsx` の設定から比較する。

曲がった形の内部交差は、上限付きの16回の二分探索で求める。曲がりが0なら従来の解析的な楕円体交差を使う。二界面屈折・Fresnel反射・距離による色吸収は継続し、全反射の追跡は追加1回まで。無限の内部反射、全面レイトレーシング、実液体の流体計算を実装したものではない。

接地平面を保つのは追加の局所変形についてであり、実際の濡れ・接触線のピン止めを再現したものではない。床の集光模様は引き続き美術上の近似。比較用の `material=physical` はThree.jsの別材質であり、専用シェーダーと同じ内部交差方式ではない。

- 型検査、38テスト、`npm run pack:itch` が成功。最新チャンクは `DropletLab-CW_Vl9N0.js`、ZIPは307.1 KB／6ファイル。500 kB超のチャンク警告は継続。
- 追加テストは触れ始め、方向転換、追いつきと解放、15〜120 Hzでの応答、体積スケール、リセット／揺れ抑制を対象とする。形状は逆変換・ヤコビアン・法線・実Float32メッシュの符号付き体積・凸性・内部反射を含む交差・接地縁の法線を確認。
- 記録は `artifacts/m1/research-build.json`、`research-shape.json`、`research-camera.json`。ビルド記録ではHTTPS上のindexと全JS/CSSがHTTP200で、ローカルのSHA-256と一致している。
- CPUの形状テストはGPU精度・スマホ性能・入力遅延の証明ではない。実画面確認の最終記録は `STATUS.md` へ集約する。今回の強さと戻り方がより良いかは、ユーザーの比較試遊で判断する。

## 比較で見たいところ

同じ色・光でリセットし、短く引く→止める→離す、端をつかむ→逆方向へ引く、壁へ当てる、を両方の感触で試す。「上部が先に応える」「広がりと厚みがつながる」「形に沿って背景や映り込みも動く」が自然に感じられるかを見る。必要に応じて「形だけを見る」と「屈折を見る」を使う。

融合・連続吸収、液膜・飛沫・音、新しい摩擦モデルなどは今回追加していない。M1で好まれる変形を選んでから次の段階へ進む。
