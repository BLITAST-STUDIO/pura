# PURA — 体験の中心

要件定義v1.0の要約。詳細と範囲は `REQUIREMENTS.md` を参照する。

> ゲームへの参加を要求する前に、現象へ参加できるものを作る。

PURAの入口は「ルールを覚えよう」ではなく、「これ、触ってみたい」。美しい水滴をつかむと動き、弾くと滑り、同じ色を取り込む。その結果を見て、自然にもう一回触れる。

**美しさは装飾ではなく、操作によって得る報酬である。**

まずは触るだけで成立する。その奥に連続吸収の進路選択や純度の工夫がある。説明より発見を優先するが、任意ヘルプや必要な情報は隠さない。

磨く対象は、広い世界でも、大量のコンテンツでもない。**一滴の存在感と、滑走しながら連続融合する数秒間。**

技術方式の名声ではなく、動いているときの説得力と指への反応で判断する。リアルさのために入力を遅らせない。融合演出のために次の融合を待たせない。

合言葉:

**触る → 滑る → 融ける → 眺める → もう一度触りたくなる。**

これは新しい加速や磁力の仕様、既存パズルの廃止、全UIの削除を許可する文書ではない。実装範囲と合格条件は正本に従う。
