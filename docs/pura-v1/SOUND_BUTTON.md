# スピーカーのアイコンに音量バー（2026-10-02）

ユーザー:「音量オンオフアイコンのところに音量バーを出現させたりできますか？」。作業ブランチ `feat/sound-popover`（`feat/maker-onboarding` の上）。

- スピーカーのアイコン（各プレイ画面の下のボタン列、自作ひとふでの上部の右）に、効果音と音楽の音量バーが出る。**タップは今までどおり音のオン/オフ**。
- 出し方: **マウスを乗せる**（アイコンからバーへ動かしても閉じない、離れて約0.45秒で閉じる）／**長押し**（0.45秒、指で。長押しのあとの離しでオン/オフは切り替わらない）／キーボードでアイコンに移る。閉じ方: ほかの場所をタップ、Escape、離れる。
- バーは中身を `VolumeSliders`（メニューにあるものと同じ部品）で共有。音が消えている間はバーは操作できず「音は消えています。アイコンで、出せます。」と出る。音を出すとすぐ使える。
- 共通の部品 `SoundButton`（`src/experiments/sound-settings.tsx`）に9画面のスピーカーを置き換え（エンドレス、ひとふで、自由、はじめる、スコアほか、道、カーリング、チャプター、自作ひとふで）。スマホの全画面盤ではメニューの音の欄（これまでどおり）と、自作ひとふでの上部のアイコン。
- 発見されにくい点: 長押しは見えない操作。メニューの音の欄で見える形で出ているので、長押しは近道の位置づけ。

## 検証

- 型検査・200テスト。実ブラウザ（GPU）`scripts/check-sound-button.mjs`:
  - PC: 乗せるとバーが出る、バーへ動かす間も開いたまま、ドラッグで効果音が 27 に変わり保存、離れると閉じる、アイコンのクリックで音が消える（アイコンの表示も変わる）、外をクリックで閉じる。
  - スマホ（タッチ）: 短いタップで切り替わる、長押しでバーが出て切り替わらない、外をタップで閉じる。警告エラー0。画像 `artifacts/sound/`。
- 同時に直したこと: 自作ひとふでの「はじめての説明を、もう一度」が、ほかのボタンの規則に負けてスマホで大きく出ていた（10pxに）。
- 未確認: 実機での長押しの感触（iPhoneの長押しメニューが出ないか、0.45秒の長さ）。
