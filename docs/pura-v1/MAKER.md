# 自分のひとふで — 小さな台エディター

2026-10-01。ユーザーの「自作台を作り、友人に遊んでもらう」「自身でクリアできたもののみ共有する」という案を受け、単色ひとふでの配置・テストプレイ・共有リンクに絞った試作。作る楽しさと、受け取って遊ぶ楽しさを確認する。無料の入口を保ち、制作を完全版の価値にする案は候補であり、課金・販売範囲の決定ではない。

入口: https://blitast-studio.github.io/pura/next/?play=maker 。作業ブランチ `feat/hitofude-maker`。身内版ルートは更新せず、mainにも未統合。

## できること

- 固定の420×560の盤面に単色の雫を2〜12個、固定石を0〜3個置く。雫・石とも大きさは3種類。盤面・壁・摩擦・融合ルールは編集しない。
- 雫や石を選び、指で動かす。数値位置指定と矢印キーも使える。重なりや盤面外の配置は防ぐ。配置の一手戻すは40回まで。
- 名前を付け、配置をこのブラウザに自動保存する。専用キー `pura-flow-maker-draft-v1` を使用。保存できない場合は表示する。初期配置は公式1番を基にした、解ける台。
- 「遊んで確かめる」で最初の配置からテストプレイ。最大12打、雫が止まってから次の一打。編集へ戻ると初期配置が残る。
- クリアを再生確認できた配置だけ共有リンクを作れる。配置・大きさ・数の変更後は再クリアが必要。名前だけの変更は有効。下書きにはクリア記録を保存せず、再読み込みしたら改めてクリアする。
- リンクを開いた人は、その台で直ちに挑戦できる。作者の打数が見え、何度でもやり直せる。友人の台を開いても自分の下書きを上書きしない。同じタブで別の台のリンクを開いた場合も切り替わる。

## 共有と再現性

共有リンクのフラグメント `#stage=...` に、版番号・初期配置・クリア時の打撃列を含める。ログインやサーバーへのアップロードは不要。作者側も受け取り側も、独立した物理シミュレーションで実際にクリアできることを確認する。「クリア済み」という自己申告だけでは受け付けない。

既存のひとふでの物理を継承し、メーカー内だけ1/120秒の固定刻み、静止後の打撃、引き幅の0.1単位化を採用してフレームレートの違いによる再現のずれを抑えた。既存コースの時間刻みやルールは変更しない。処理量を制限するためリンクは4096文字、打撃は12回、各打撃の再生は最大12秒。版1以外は明示的な回復画面へ。将来物理を変える場合は既存リンクへの対応を別途設計する。

端末の共有シート／コピーから、ユーザー自身がリンクを渡す。アプリはメッセージを自動送信しない。作成・受け取りに料金やアカウントは不要。作者本人の証明、公開作品一覧、サーバーへの投稿、購入権利は未実装。投稿型にする場合はサーバー側の再生検証・作品保存と管理を追加する。

## 連続して打てるように（2026-10-02）

ユーザー:「自作ひとふでで、エディットして試すとき、ひとつめをはじいたあと、ふたつめ以降を、ひとつめの雫の動きが終わる前でも好きなタイミングで打てるようにしたい。直感的に次のものも動かせるように（通常盤ではなかった挙動かも）」。作業ブランチ `feat/maker-chain`。

### 原因

- 自作ひとふでの `grab`（雫をつかむ処理）に「盤面の雫がすべて止まっているときだけ」という条件があった（Codex の実装）。共有リンクの検証が「毎回、静止状態から次の一打」を前提に作られていたため。
- ひとふでの雫は、ゆっくり滑る時間が長い（6〜7秒）。実ブラウザで確かめたところ、2発目のドラッグは無視され、5秒後も「雫が止まるまで待ってね」のままだった。
- **通常のひとふで（18ホール）は、この制限がない**: 条件は「つかむ雫が止まっているか（秒速30未満）」だけで、ほかの雫が動いていても別の雫を打てる。自作ひとふでだけの挙動だった。

### 直し方

- つかめる条件を通常のひとふでと同じに（つかむ雫が止まっていればよい。動いている雫そのものはつかめない）。「止まるまで待ってね」の表示を削除。
- 共有リンクの検証を、打つタイミングを記録する形（版2）にした。各打に、つかんだ刻み `g` と離した刻み `r`（固定の物理の刻み 1/120 秒を、開始から数えた回数）を入れる。検証側が同じ刻みで再現するので、フレームの速さ（30・60・120・144Hz）に関係なく同じ結果になる。
- 版1のリンク（試作で数日だけ作れたもの、刻みなし）も、静止状態から打つ形で引き続き開ける。刻みのない版2のリンクは拒否する。
- 悪用への備え: 刻みは整数で前に進むだけ（つかむのは前の離しより前にならない、離すのはつかむより前にならない）、全体で約3分（18,000刻み）まで。上限を超える偽の記録は即座に拒否（0ミリ秒）。

### 検証

- 型検査・189テスト（動いている最中に別の雫がつかめる・動いている雫自体はつかめない、重なり打ちの記録がフレームの速さ（120・60・30Hz）に依らず同一で再現できる、刻みの不正・版の違い・クリアにならない打撃列の拒否、版1のリンクが開く）。
- 乱数での負荷確認: ばらばらのフレーム時間・待ち時間・狙いで600回遊ばせ、クリアした307回（うち300回が重なり打ち）の記録がすべて検証を通った。不一致0、検証の最大は3.8ミリ秒。
- ブラウザ（GPU、スマホ幅、実際のポインター操作）:
  - 直す前（公開 `/next/`）: 1発目を離して150ミリ秒後に2発目をドラッグしても無視（「1/12打」のまま、「止まるまで待ってね」）。
  - 直した後: 同じ操作で2発目が打てて、さらに最後の一打でクリア（3打）、共有リンク（版2、431文字）が使える。そのリンクを友人側で開くと「作者記録 3打」、同じ台を重なり打ちでクリアして「ひとつに3打 · 作者と同じ」。警告エラー0。画像 `artifacts/maker/chain-author.png`・`chain-friend.png`。
- 直感的さについて: 動いている雫を直接さわるのは打てないが、止まっている別の雫を直接さわれば打てる。空いた床から引く操作は、選択中の雫が動いている間は反応しない（通常のひとふでと同じ）。
- 未確認: 実機での打ち心地。
