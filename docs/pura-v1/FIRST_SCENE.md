# 最初の一面 — 澄んだ道

2026-09-17。柔らかい混色までのユーザー承認を受け、触り心地をゲームの目標へつなぐ最小の一面。試遊入口は `?play=first`。旧標準入口、融合比較、一粒の入口は維持する。

## 遊び

三滴のシアンをまとめ、左上の輪へ運ぶ。二滴のローズも動かせるが、触れると混ざる。輪には全体を収め、指を離して落ち着かせる。時間制限、強制ゲームオーバー、次の面への強制遷移はない。達成しても操作でき、「もう一度遊ぶ」か「自由に混ぜる」を選べる。

シアンの成分量を全部一滴へ集め、その滴のシアン比率90%以上が目標。表示する「仕上がりの純度」は、シアンを含む全滴を集めた場合の予測比率（全シアン量／それらの全質量）。途中で別の色が主成分になっても目標色は変えない。画面に計算対象を説明する。

輪の半径103、シアン初期半径44×3、ローズ半径55／50。論理盤面550×650を固定し、画面サイズは投影で吸収する。正確な配置は `src/experiments/purity-scene/simulation.ts` の `FIRST_SCENE`。下側から左側へ回る安全な道を、自動テストとブラウザの実操作で確認した。ローズを先に動かす自由も残す。

ゴールは位置だけで瞬間成功にせず、円内に物理半径全体が入り、掴みなし・速度28未満で0.45秒滞在したとき達成する。自動吸着・速度補正を追加しない。達成済みはその周回中保持し、その後遊んでも取り消さない。操作履歴を戻すと、その時点の達成状態へ戻る。

## 取り消し

有効な掴みの直前に、全滴の位置・成分と達成状態をコピー。直後の融合連鎖と解放後の滑走も同じ操作に含む。最大50操作。戻すと色と配置を復元し、速度は0へする。これは厳密な時間逆再生ではなく、やり直し用の静止した配置への復帰。履歴や設定変更で旧ゲームの保存を上書きしない。

復元時は物理コアと表示を再構築し、融合イベント・掴み・形状の残留を消す。復元IDを1000以上へ割り当て、コアの次の融合IDと衝突させない。サイズ変更でも盤面・履歴を保存。リセットだけが履歴と達成を消す。

## 共用とルールの境界

好評の `m2-bloom-approved-20260917` / `38235e5` を保存。新画面は同じ融合レンダラーにシミュレーションとゴールの表示情報を渡す。材質、内部のbloom、表面、指への応答、速度継承は共用し、再調整しない。レンダラーはゲームの達成条件を決めない。

この一面はM2自由混色と同じ全色接触融合を意図的に選ぶ。旧ゲームは従来の異色反発／条件付き混色を継続。今後の基本モードを全色接触へ確定したという意味ではない。要件G-05/G-06/G-08/G-11の旧ルールと、新しい道選びの比較を混同しない。ダブルタップ分離はこの一面へ入れず、明示的な取り消しを使う。
